# 工艺质量 RandomForest 模型卡

## 模型用途

- 模型 ID：`process-quality-random-forest-v1`
- 任务：根据浮选工艺参数预测精矿二氧化硅含量 `silica_concentrate_pct`
- 算法：`RandomForestRegressor`
- 定位：课程设计可复现基线、接口联调和部署演示
- 非预期用途：生产闭环控制、自动根因认定或未经现场验证的质量放行

## 数据与预处理

数据来自 Kaggle `Quality Prediction in a Mining Process`，许可登记为 `CC0: Public Domain`。正式训练 CSV 共 737453 条记录、24 列，SHA-256 为 `ae0231a0bd2e14aac39cf978d81db6c71907a42aade19327816692c4e30cb956`。

预处理将本地化逗号小数转换为浮点数，把时间戳向下取整到小时，并对同小时记录取均值，最终得到 4097 条样本。7 个浮选柱气流和液位分别聚合为两个均值特征。

输入特征共 9 项：

- 入料铁品位、入料二氧化硅
- 淀粉流量、胺流量、矿浆流量
- 矿浆 pH、矿浆密度
- 浮选柱平均气流、浮选柱平均液位

`iron_concentrate_pct` 与目标高度相关但属于后验质量字段，因此从部署特征中排除。该措施降低明显泄漏风险，但不能证明剩余特征不存在时间或流程相关偏差。

## 训练与评估

数据按时间顺序切分，不随机打乱：训练 2867、验证 615、测试 615。模型选择以验证集 MAE 为准，最优参数为：

```json
{
  "n_estimators": 200,
  "max_depth": 12,
  "min_samples_leaf": 4
}
```

| 指标 | RandomForest | 中位数基线 |
| --- | ---: | ---: |
| MAE | 0.87194 | 0.97110 |
| RMSE | 1.11653 | 1.27166 |
| R² | 0.13100 | -0.12725 |

RandomForest 的测试 MAE 相对基线改善 `10.21%`。时间外推测试显著严格于随机切分，当前 R² 较低，因此模型只作为课程基线，不应表述为生产现场高精度模型。

## 解释与风险

全局特征重要性前三项为浮选柱平均气流、胺流量和浮选柱平均液位。重要性只反映模型在当前数据中的预测关联，不能直接解释为工艺因果关系。

推理服务将预测值按训练目标的 `q50/q80/q95` 分位数映射为相对风险，并对超出训练集特征范围的输入生成告警。分位数阈值和范围告警均需结合现场质量标准二次校准。

## 部署产物

- joblib：`models/process-quality-rf/model.joblib`
- ONNX：`models/process-quality-rf/model.onnx`，opset 17
- 清单：`models/process-quality-rf/manifest.json`

模型二进制和完整数据被 `.gitignore` 排除。joblib 与 ONNX 已在独立样本上完成一致性验证，128 条输入的最大绝对差为 `1.47e-6`。

## 已知限制

- 数据来自单一公开浮选流程，不能直接泛化到其他产线。
- 小时均值会压缩分钟级波动和异常尖峰。
- 当前模型未加入漂移检测、在线再训练或现场校准。
- 全局特征重要性不是单次预测的局部解释。
- 训练指标和风险分级不能替代企业验收标准与人工复核。
